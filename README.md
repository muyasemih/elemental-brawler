# ⚡ Elemental Brawler _(working title)_

> An online multiplayer 2D platform fighter: pick one of 10 elemental heroes, master their abilities and fight across 10 hand-crafted arenas.

**Status:** In development · Coming to Steam · Built with **Unity 6 (C#)**

> 🔒 This is a **showcase repository**. The game is a commercial project, so the source code and assets are kept private.
> Code samples or a walkthrough can be shared with recruiters on request.

---

## 🎮 About the Game

Fast, readable, ability-driven combat. Every hero has a basic attack, a unique skill and an ultimate.

**10 playable heroes**, each with its own playstyle:
🔥 Fire Mage · ❄️ Ice Wizard · 🌊 Water Mage · 🌪️ Air Bender · ⚡ Electric Bender · 🪨 Rock Fighter · ✨ Light Warrior · 🥷 Ninja · ☀️ Solar Trickster · 🛡️ Knight

**10 arenas:** island, shipwreck, ice cave, castle, canyon, neon city, forest, power plant, temple and volcano.

- 👥 Free-for-all and **Red vs Blue team** matches with multiple rounds
- 💀 Sudden death, kill feed, leader crown and end-of-match statistics
- 🎯 Training mode with practice dummies and an in-game tutorial
- 👀 Spectator mode for eliminated players
- ⌨️ Rebindable controls, audio settings and themed menus

## 🛠️ Technical Highlights

- **Online multiplayer via Steam** — lobbies and room codes, built on **Mirror** with a Steam transport
- **Custom networking layer** on top of Mirror: networked objects, RPC attributes and synchronized state (health, facing direction, abilities)
- **Object-oriented character system** — all heroes share a common base class; abilities, cooldowns and ultimates are composed per hero
- **Game feel** — hit-stop, camera shake, damage numbers, ghost trails and elemental VFX
- Around **80 gameplay scripts** written from scratch, developed incrementally with Git
